# 🐍 Snake Game

A small Snake game made in Python using the `turtle` library.  
The snake moves with the arrow keys, eats apples.

![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)

---

## 🎮 How to play

- **UP arrow** → go up
- **DOWN arrow** → go down
- **LEFT arrow** → go left
- **RIGHT arrow** → go right

The green square is the snake's head.  
The red circle is the apple: when you touch it, it jumps to a random spot. 🍎

The snake **cannot leave** the window: it stops at the edges.
